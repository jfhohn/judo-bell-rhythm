# Roadmap

## Planned Enhancements

### Tournament Phase 2 (Tournament Organizer Software)
- [ ] Competitor database (CRUD + CSV import)
- [ ] Bracket generation (single-elim, double-elim, round-robin, pools)
- [ ] Fightorder generation across multiple mats
- [ ] Mat assignment + multi-mat scoreboards synced over the network
- [ ] Match results export (CSV / JSON / PDF certificates)
- [ ] Organizer dashboard with at-a-glance event state
- [ ] Optional registration + waiver collection (free for organizers)

### Class Bell Priority
- [ ] Export/import schedules (JSON) - Backup and share schedule configurations
- [ ] Improved bell timing accuracy - Ensure bells always fire precisely at section end and 2-minute mark

### Nice to Have
- [ ] Custom sound uploads - Allow instructors to use their own audio files for bells
- [ ] Country flags on tournament scoreboard
- [ ] Match history / past-matches review page
- [ ] Configurable spectator display themes (high-contrast, projector mode)

## Completed
See [changelog.md](./changelog.md) for shipped features.

## Out of Scope
The following features have been considered but are not planned:
- PWA support
- Multi-device sync / cloud storage for the class bell
- Custom color picker for sections
- Voice announcements
- Student-facing display mode for the class bell
- Analytics/usage tracking
- Large-scale points-based tournament compliance (intentionally ceded to Smoothcomp)
